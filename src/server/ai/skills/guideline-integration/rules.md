# Rules for Guideline Integration Skill
1. **Explicit Citing**: Always cite the exact guideline name, publishing body, and version/year (e.g., "MOH Kenya Asthma Guidelines 2024").
2. **First-Line vs. Alternative**: Distinguish clearly between first-line therapy, second-line/alternative therapies, and adjunctive therapy options.
3. **Guideline vs. Commentary**: Clearly separate official guideline recommendations from personal or educational commentary.
