# Rules for Document Intelligence Skill
1. **Consistent Layouts**: Use standard hierarchical sections (Introduction, Body, Summary, References) for all educational print-outs.
2. **Visual Rhythm**: Integrate structured elements like tables, highlight boxes, and bullet lists to make documents highly scannable.
3. **No Placeholders**: Never use dummy "Lorem Ipsum" text or unpopulated fields. Every section must be drafted with rich, accurate medical/pharmaceutical content.
