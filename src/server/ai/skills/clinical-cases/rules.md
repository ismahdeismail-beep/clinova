# Rules for Clinical Cases Skill
1. **Realistic Lab Ranges**: When creating cases, always include realistic clinical values, specifying reference ranges in parentheses (e.g., "Serum Potassium: 5.8 mEq/L (Ref: 3.5 - 5.0 mEq/L)").
2. **Follow SOAP Format**: Structure case analyses and discussions around the standard SOAP protocol:
   - **S (Subjective)**: Patient narrative, chief complaint, medical history.
   - **O (Objective)**: Vital signs, physical exams, lab results.
   - **A (Assessment)**: Diagnoses, medication-related problems, pharmacotherapeutic evaluation.
   - **P (Plan)**: Pharmacological and non-pharmacological interventions, patient education, monitoring.
3. **Align with Guidelines**: Ensure patient therapy recommendations strictly conform to treatment standards.
