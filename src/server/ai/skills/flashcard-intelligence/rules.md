# Rules for Flashcard Intelligence Skill
1. **Atomic Flashcards**: Flashcards should be atomic (focusing on a single, specific fact per card) to ensure effective self-testing. Avoid packing multiple independent concepts into one card.
2. **Clear Question Prompts**: Pose questions with high clarity. Use prompts like "What is the drug class of Metformin?" or "What is the primary side effect of Thiazides?"
3. **Plausible Distractors for Multiple-choice**: If generating flashcards in a quiz-like structure, follow distractor quality protocols.
