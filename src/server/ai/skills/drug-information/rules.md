# Rules for Drug Information Skill
1. **Dose Adjustments**: Always state renal or hepatic dose adjustments for moderate/severe impairment if relevant. If no adjustment is required, state it clearly.
2. **Mechanism of Action**: Explain the molecular mechanism (e.g. receptor binding, enzyme inhibition) first, followed by the secondary physiological effect (e.g. vasodilation, diuresis).
3. **High-Yield Safety Profile**: Highlight critical black box warnings, high-severity drug-drug interactions, and common or severe adverse events (ADRs).
4. **Patient Counseling**: Include 2-3 specific, actionable advice points for the patient (e.g., "take with or without food", "avoid alcohol").
