# Rules for Export & Print Skill
1. **Clean Markdown Hierarchies**: Use structured header levels (e.g., `#`, `##`, `###`) progressively. Do not skip header levels.
2. **Page-break Compatibility**: Use standard markdown markers (e.g. horizontal rules `---`) to indicate natural section divides suitable for page-breaks.
3. **Optimized Table Formats**: Ensure markdown tables are formatted with aligned pipe characters and have concise column headers to avoid horizontal clipping when printed.
