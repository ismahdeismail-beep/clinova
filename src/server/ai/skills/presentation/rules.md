# Rules for Presentation Skill
1. **Utilize Tables for Comparisons**: Always use comparison tables when discussing differences between drugs in the same class (e.g., comparing Loop vs. Thiazide diuretics).
2. **Clinical Algorithm Flow**: Use clear text-based sequential blocks (e.g., Step 1 -> Step 2) or ASCII flow diagrams to model clinical decision trees.
3. **Important Safety Highlights**: Enclose critical toxicities, contraindications, or dose-limiting warnings in a visual callout block or bolded highlight panel.
