# Rules for Semantic Search Skill
1. **Synonym Matching**: Map lay terms or colloquial expressions (e.g., "water pill") to appropriate pharmacological terms ("diuretic") during search expansion.
2. **Medical Terminology Mapping**: Resolve brand-to-generic mappings (e.g., Lasix → Furosemide) automatically when searching medical reference guidelines.
3. **Concept Affinity**: Proactively suggest closely related clinical concepts even if they do not contain exact word overlaps.
