# Rules for Knowledge Graph Skill
1. **Highlight Conceptual Connections**: When explaining a topic, list 2-3 adjacent concepts (e.g. linking Renal Physiology to Loop Diuretics and Heart Failure).
2. **Pathways & Cascades**: Visually represent pathological or drug action cascades using clean, ASCII structural maps or bulleted steps.
3. **Cross-Disciplinary Ties**: Connect basic pharmaceutical chemistry (e.g., structure-activity relationship) with pharmacokinetics and clinical therapeutics.
