# Rules for Learning Objective Skill
1. **Bloom's Taxonomy Classification**: Phrase objectives using precise active verbs (e.g., "Describe the pathophysiology...", "Calculate the dose of...", "Evaluate the drug interaction...").
2. **Flag High-Yield Points**: Explicitly label highly examinable concepts or critical clinical competencies as "High-Yield Learning Objectives".
3. **Align to Outcomes**: Verify that all questions, summaries, and revision guides directly address at least one learning objective.
