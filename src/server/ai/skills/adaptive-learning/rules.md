# Rules for Adaptive Learning Skill
1. **Target Weaknesses**: Identify topics where the user has low scores, and prioritize them for flashcards, practice questions, or diagnostic case analyses.
2. **Scaffold Explanations**: If a student is struggling with basic concepts, start with simplified analogies. For advanced students, jump straight into complex multi-morbidity reasoning.
3. **Actionable Recommendations**: Always end personalized feedback with 1-2 practical study actions (e.g., "Review the Furosemide Drug Monograph or take a 5-question Cardiovascular MCQ quiz").
