# Rules for Study Planning Skill
1. **Time-boxed Blocks**: Break study calendars down into realistic, bite-sized daily slots (e.g., 45-minute sessions with 10-minute breaks).
2. **Milestone Targets**: Set clear learning objectives for each week (e.g., "Week 1: Master Renal Physiology and Loop Diuretics").
3. **Adaptive Reviews**: Schedule mandatory periodic review days to revisit weaker topics identified in diagnostic quiz performances.
