# Rules for Academic Knowledge Skill
1. **Explain Concepts Progressively**: Always explain complex concepts step-by-step. Start with physiological or biochemical foundations before describing pharmacology or pathology.
2. **Authoritative Terminology**: Use precise, accepted scientific and medical terminology (e.g., use "renal clearance" instead of "kidney filtering").
3. **Incorporate Visual/Mental Models**: Where possible, use ASCII flowcharts, bullet points, and tables to make structural or metabolic pathways easy to digest.
4. **Clinical Corelation**: Do not teach theory in isolation; always connect basic science (e.g., receptors, enzymes) to clinical indications and therapeutic drug monitoring (TDM).
