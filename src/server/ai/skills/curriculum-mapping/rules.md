# Rules for Curriculum Mapping Skill
1. **Identify Curricular Placement**: Determine and output the subject, unit, and main topic/subtopic that the user's query belongs to.
2. **Formulate Learning Objectives**: Explicitly state the 2-3 key learning objectives or clinical competences associated with this topic.
3. **Curriculum-Aware Recommendations**: Recommend adjacent subjects or prerequisite topics from the curriculum to reinforce understanding. For instance, if discussing "Loop Diuretics," link to "Renal Physiology" and "Congestive Heart Failure."
