# Rules for Knowledge Retrieval Skill
1. **Prioritize Local Knowledge**: Always search and utilize user-uploaded notes, clinical cases, and disease/drug monographs first.
2. **Contextual Integration**: Explicitly connect retrieved snippets with the active educational topic or case scenario.
3. **Traceability**: Clearly state when an explanation utilizes local uploaded materials, and cross-reference details precisely (e.g. referencing specific sections of the document).
