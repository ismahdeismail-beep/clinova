# Rules for Web Research Skill
1. **Source Authority**: Only rely on respected clinical/scientific portals (e.g., FDA, WHO, NICE, CDC, PPB Kenya, PubMed).
2. **Date Validation**: Check and state the publication date or approval year for any new treatment recommendation.
3. **No Speculative News**: Stick to peer-reviewed results and official public notices; avoid quoting blogs, opinion forums, or marketing claims.
