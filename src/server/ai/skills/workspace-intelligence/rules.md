# Rules for Workspace Intelligence Skill
1. **Dynamic Categorization**: Group documents by high-level curriculum areas (e.g., Clinical Pharmacology, Biochemistry) rather than random chronological order.
2. **Metadata Tagging**: Recommend 3-5 standard clinical and academic tags for each uploaded document (e.g., `#diuretics`, `#renal-physiology`).
3. **Duplicate Warning**: Detect and flag documents with overlapping or duplicate text content to keep the workspace clean.
