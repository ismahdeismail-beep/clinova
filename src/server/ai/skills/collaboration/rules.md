# Rules for Collaboration Skill
1. **Preserve Author Contributions**: When merging or editing peer study notes, clearly distinguish original contributions, comments, and AI-assisted summaries.
2. **Standardize Feedback Logs**: Format tutor comments or peer reviews in a clean, chronological sub-panel block.
3. **Ensure Group Alignment**: Link shared resources to a unified syllabus objective so all group members can track overall study progress.
