# Rules for Disease Knowledge Skill
1. **Clinical Features Grouping**: Classify clinical features into "Symptoms" (subjective patient experiences) and "Signs" (objective clinical findings).
2. **Investigations Hierarchy**: Structure diagnostic investigations into:
   - Bedside tests
   - Laboratory investigations
   - Imaging and special tests
3. **Differential Diagnosis**: Provide at least 2 key differential diagnoses, highlighting how to distinguish them clinically or pathologically.
